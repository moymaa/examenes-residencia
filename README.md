# Simuladores Psiquiatría

Material de estudio para la residencia de Psiquiatría, publicado con GitHub Pages. El acceso pide correo y contraseña; los bancos, lecturas y personajes van cifrados (`*.enc`).

| Carpeta | Contenido |
|---|---|
| `simulador-puem/` | Simulador PUEM: bancos de años previos, casos simulados, lecturas por tema, simulacros por año y simulador real |
| `simulador-consejo-paido/` | Simulador del Consejo de Paidopsiquiatría |
| `tcc/`, `genetica/` | Exámenes ya cerrados |
